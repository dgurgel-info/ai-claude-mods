# ai-claude-mods

Mods para Claude Code.

| Mod | Descrição |
| --- | --- |
| [claude-mods-contexto](claude-mods-contexto) | Carga da janela de contexto e cota de 5h acima do prompt |
| [claude-mods-tempo](claude-mods-tempo) | Previsão do tempo e maré da sua localidade junto ao prompt |

## Instalação

```
/plugin marketplace add dgurgel-info/ai-claude-mods
/plugin install contexto@ai-claude-mods
/plugin install tempo@ai-claude-mods
```
